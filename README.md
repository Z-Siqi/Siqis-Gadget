# Siqi's Gadget

**Now is for personal use**

### Current Feature (Android)
* Circle Length - Convert between area, diameter, circumference, radius.
* Length Unit Conversion - Support to convert between all SI Units, Imperial Units, and Chinese Units.
* Hormone Units Conversion - View all units that can be converted to E2, T, P, LH, FSH.
* Screen Information - Provide some information about the screen / window (e.g. screen px size, night mode, etc.)
* System Information - Provide some system information (e.g. SDK version, ABI, etc.)

### Supported Platform
* Android
* Desktop (in developing...)
